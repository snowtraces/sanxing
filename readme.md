## 缘起与理念

在信息嘈杂、心绪纷扰的现代生活中，「三省」致力于为修身者打造一个安静、内敛且极度私密的观心之所。

告别花哨拥挤的传统软件交互，「三省」坚持 <strong>“以减为增，以墨化意”</strong>，采用仿古宣纸底色与焦墨大宋体，搭配自然写意的彩色水墨水印，让每日的反省与体悟回归中国文人手札书写本味。

## 核心特性

### 1. 纯端侧离线语音识别 (Edge-Offline ASR)
- **绝对隐私与零网络依赖**：基于阿里达摩院 **SenseVoice** 语音模型与 **Sherpa-onnx** 运行时，录音与识别全在手机本地芯片毫秒级推理完成，敏感省察心事绝不上传云端。
- **主流胶囊麦克风交互**：摒弃遮挡视线的浮层弹窗，以克制的呼吸波纹与状态动效在录音按钮内直观反馈，文案自适应防换行。
- **前置模型下载保障**：首次使用离线语音时具备平滑进度引导与校验，杜绝意外闪退或误操作。

### 2. AI 智慧省思归纳
- **省察与对治**：自动从日常叙述中提炼出：
  - <strong>「原委始末」</strong>：客观陈述事实经过；
  - <strong>「省 · 偏差执念」</strong>：以第一人称指出当时的心念偏差与不当举止（不应该怎样）；
  - <strong>「悟 · 对治心法」</strong>：凝练下一次的行事准则与精进良方（应该怎样）。
- **智能分类归纳**：自动归入「工作」、「学习」、「日常」、「情绪」、「方法」、「策略」、「交际」、「修身」等维度。

### 3. 写意水墨文字背景水印
- **原生写意上色与完整气韵**：每个分类均配有专属大写意水墨字水印，完整保留字形四周散落的 <strong>飞溅墨星、枯笔飞白与宣纸洇润水痕</strong>。
- **自适应视觉中心校准**：通过像素级几何重心算法，修正了 AI 生成大图布局不一的问题，各分类水印在正方形切片中上下左右 <strong>严格对称居中、留白舒朗</strong>。
- **清浅通透衬托**：适度半透呈现于卡片右下角，为卡片定下分类基调，绝不喧宾夺主干扰正文阅读。

### 4. 文人金石风骨排版
- **大宋体标题**：卡片标题采用焦墨大宋体（`FontFamily.Serif` 17.5sp），沉着大气，具金石之骨。
- **高对比黑体正文**：小字与原委采用高对比度系统黑体（14sp/13sp），彻底解决传统衬线小字发虚发灰的辨识痛点。
- **极简去框设计**：顶行去除生硬分类外框，仅保留简净时间戳与专属印色微点，整洁空灵。

### 5. 心镜 · 水墨坐禅气泡画像
- **心性镜像**：主画面呈现水墨坐禅小僧形象，上空悬浮近期反复出现的省思执念气泡。
- **AI 相似度聚合**：后台智能归纳重复行为偏差，高频痛点加重显示，通过自我观照击破气泡，修持身心。

### 6. 古籍手帖左右翻阅
- 详情页卡片完美支持 <strong>横向左右滑动手势 (Swipe / Horizontal Drag)</strong> 与平滑过渡动效，宛如翻阅一册连绵的宣纸法帖。

### 7. 硬件级安全与私密备份
- **硬件密钥库加密**：LLM API 密钥由 AndroidKeyStore 硬件级 AES-GCM 安全加密，杜绝明文泄露。
- **本地参数化存储**：纯本地 SQLite 存储，严格防注入与边界校验。
- **完整快照迁移**：支持全量反省、分类与心镜画像数据的 JSON 本地备份与无损导入。

## 技术栈

| 层次 | 选型 / 组件 |
| :--- | :--- |
| **平台基底** | Android 7.0+ (API 24+), 编译目标 API 34 |
| **编程语言** | Kotlin 1.9.24 (JVM 21) |
| **UI 框架** | Jetpack Compose (BOM 2023.01.00 + Material3) |
| **端侧 AI 推理** | Sherpa-onnx (C++ / JNI) + ONNX Runtime (SenseVoice-small) |
| **本地数据库** | Android SQLite (带外键约束与事务一致性保障) |
| **安全存储** | AndroidKeyStore (AES/GCM/NoPadding) |
| **包名标识** | `com.snowtraces.sanxing` (取自“三省吾身”之 *xǐng*) |

## 编译与构建

### 1. 环境要求
- Android Studio Hedgehog / Iguana / Jellyfish 或更高版本
- JDK 21
- Android SDK 34 (Build-Tools 34.0.0)

### 2. 构建 APK
```bash
# 运行单元测试
./gradlew testDebugUnitTest

# 构建 Debug 安装包
./gradlew :app:assembleDebug

# 通过 ADB 直接安装至手机
adb install -r app/build/outputs/apk/debug/app-debug.apk
```
