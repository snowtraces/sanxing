# 首页与历史 · V1

状态：待评审 · 模块 `review`

## 目标与交互

- 底部主导航依次为「首页」「历史」「画像」，冷启动默认打开首页。
- 首页以一张大卡片展示随机历史「悟」。每次冷启动或主动点击「换一条」时抽取。候选至少有两条时，主动换一条须展示与当前不同的记录。详情关闭后维持原卡片，当前记录被删除时重新抽取。无记录时展示新增入口。
- 历史以小卡片展示主题、分类、发生时间和一段预览，默认按发生时间倒序。同一时间按创建时间及记录 ID 稳定排序。搜索实时匹配主题、分类名称、问题描述、省和悟，忽略首尾空白与英文字母大小写，支持中文子串。无结果时可清除搜索。
- 详情卡片展示六项字段。分类使用固定墨色系的淡色点缀，分类名称始终可见。关闭详情后返回入口，历史路径保留搜索词和列表滚动位置。

## 输入与验收

输入由 `journal` 提供。详情按稳定 ID 打开，记录变更后读到最新值。

1. 创建两条带不同「悟」的记录，首页可随机展示其中一条，换一条必定出现另一条。卡片打开对应记录，返回时仍显示同一条。
2. 历史正确排序，搜索中文片段或分类名时只展示命中记录。进入详情然后返回，搜索词与列表位置可见且保持。
3. 空库、有记录但搜索无命中、当前记录被删除三种状态都提供对应反馈及可操作入口。
