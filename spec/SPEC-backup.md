# 本机备份与恢复 · V1

状态：待评审 · 模块 `backup`

## 目标与交互

- 在设置中点击「导出备份」，通过 Android 文件选择器创建 UTF-8 JSON 文件，写入同一数据库快照中的复盘、分类、画像分组及点击状态。完成后提示文件名与记录数。
- 点击「从备份恢复」，选取文件后先校验并展示源文件的导出时间、记录与分类数量。界面提示恢复会替换当前的复盘、分类和画像数据，用户确认后一次性应用。取消或校验失败时保持原数据，恢复成功后刷新首页、历史和画像。
- 备份包含个人复盘文本，导出时说明文件由用户自行保管。LLM 地址、模型和密钥留在本机配置中。

## 文件契约

JSON 根对象包含 `schemaVersion`、`exportedAtMillis`、`reflections`、`categories` 和 `portraitThemes`。V1 使用 `schemaVersion: 1`，ID、时间和状态按原值保存。读取时校验版本、字段类型、分类引用、唯一 ID、主题来源与点击次数。恢复以一次事务写入全部相关表。导出和导入都支持取消文件选择，并在文件 I/O 失败时显示明确反馈。

## 验收

1. 导出包含中文记录、自定义分类和已隐藏气泡的备份，在另一份空数据中恢复，三个页面能读取相同业务状态。检查文件中没有 API 密钥及连接配置。
2. 对已有记录的设备发起恢复，取消确认后原数据保持一致，确认后以备份中的记录、分类与画像状态为准。
3. 使用截断 JSON、未知版本、重复 ID、悬空引用和写入中途故障验证恢复失败。失败后重新打开应用，原数据仍完整，界面可以重新选择备份。
