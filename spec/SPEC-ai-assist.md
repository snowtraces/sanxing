# AI 整理与设置 · V1

状态：待评审 · 模块 `ai-assist`

## 目标与交互

- 从画像页进入设置，填写 OpenAI 兼容 API 的 HTTPS Base URL、模型名和 API 密钥。密钥屏蔽显示，可更新或清除。提供「测试连接」，使用固定测试文本。
- 编辑页点击「AI 整理」后，将当前草稿与可选分类发给用户配置的服务。首次使用前告知发送内容和服务地址。整理结果作为预填内容，可逐项修改，原始草稿仍可恢复。用户确认保存后才写入复盘记录。
- 请求期间提供进度和取消入口，避免重复提交。配置缺失、超时、网络失败及响应格式不正确时保留草稿，显示可理解的提示，支持继续手动录入或重新尝试。

## 接口契约

调用用户配置的 API 基础路径下的 `POST /chat/completions`，使用 Bearer 密钥。解析模型返回的结构化内容，读取标题、分类 ID、问题描述、省和悟，逐项校验类型和必填字段。标题使用简短白话。遇到未知或已归档的分类时保留编辑器的有效选择，缺少有效选择时由用户确认。模型整理遵循原文，建议用第一人称表述并由用户审阅。

为 `portrait` 提供独立的候选判断请求，输入为当前「省」及相似候选的「省」，输出为是否属于同一行为以及 2～5 字的中文标签。画像自动发送由画像设置中的独立开关控制，默认关闭。

## 验收

1. 配置测试使用固定样例。密钥不会出现在错误提示、日志或备份中，清除后请求要求重新配置。
2. 使用返回合法字段的模拟服务整理草稿，编辑页收到建议且数据库中仍无新增记录。用户修改后保存，详情显示最终确认的值。
3. 模拟超时、取消、非成功状态、非法 JSON、非法分类和重复点击。草稿始终可继续编辑，非法或过期响应无法覆盖用户之后的修改。
