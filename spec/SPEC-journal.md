# 复盘录入与分类 · V1

状态：待评审 · 模块 `journal`

## 目标与交互

- 从首页或历史页点击「新增」打开复盘编辑页。用户可以键入原始描述，或在语音识别结果返回后继续编辑同一草稿。语音识别不可用、失败或取消时保留已有文字，并保持键盘输入可用。
- 编辑页包含时间、主题、分类、问题描述、「省」和「悟」。时间默认当前时间且可修改，主题用简短白话，「省」记录需要反思的行为，「悟」记录下一次可以执行的行动。所有字段保存时必填，纯空白视为未填写。
- 保存后可以从详情重新编辑或删除。删除前确认，保存或删除失败时提示原因并保留界面状态。离开存在未保存修改的编辑页时提示用户确认放弃。
- 初始分类为学习、方法论、情绪、日常、工作、策略、交际。用户可以新增、重命名、归档和恢复分类。分类名去除首尾空白后唯一，至少保留一个可选分类。归档分类的历史记录仍显示其分类，编辑已有复盘时可以保留原分类。

## 数据契约

复盘包含稳定 ID、发生时间戳、标题、分类 ID、问题描述、省和悟，并记录创建及最后更新时间。分类包含独立稳定 ID、名称、归档状态和显示顺序。重命名沿用原分类 ID，新建、编辑和删除操作各自以一次本机事务提交。

`review` 读取已保存记录及分类。 `ai-assist` 使用草稿文本与可选分类，回填编辑页。 `portrait` 读取当前已保存的「省」，并能识别被修改或删除的来源。 `backup` 可读取一致的快照并在事务内替换记录与分类。

## 验收

1. 手动填写六项并保存，关闭后重开应用，记录及字段保持一致。重复点击保存只产生一条记录。
2. 编辑并保存原记录后仍使用原 ID，历史及详情显示更新后的值。删除确认后该记录从历史、随机候选和画像来源中移除。
3. 语音结果可编辑，取消识别保留草稿。任一必填项为空时有对应提示，已有输入保持可编辑。
4. 分类重命名后历史卡片显示新名称，归档后新录入的分类列表隐藏该项，已有记录仍可打开与编辑。
